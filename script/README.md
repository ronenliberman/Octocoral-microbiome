# script

Analysis scripts. The run order, inputs and outputs of every script are in
[../HELPER.md](../HELPER.md); the decisions they implement are in
[../RULES.md](../RULES.md).

- `*.R` here: round-2 community analysis (diversity, PERMANOVA, core
  microbiome, ANCOM-BC2).
- `Editor_round3/`: round-3 ASV verification, stable labels, bacterial trees,
  Figures 3–6 and the supplementary workbook.
- `archive/`: superseded scripts kept for the record. They are not part of the
  pipeline and their paths are the original ones.
